# Palestine-Body-Count-Casualty-Prediction-System
An end-to-end data analysis and machine learning project that tracks historical conflict metrics and provides real-time casualty estimations using an interactive web application.
This project processes historical conflict datasets to uncover temporal trends, injury breakdowns, and fatalities. It integrates a trained Ridge Regression machine learning model backed by automated preprocessing pipelines (SimpleImputer) to predict conflict outcomes based on rolling averages and lag features.
